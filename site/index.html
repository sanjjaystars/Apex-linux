Getting Started

Simple 3-Step Installation

1️⃣

Download & Flash

Download the ISO above and flash it to a USB drive using dd, Ventoy, or BalenaEtcher:

sudo dd if=apex-linux.iso of=/dev/sdX bs=4M

2️⃣

Boot Live USB

Reboot your PC and select UEFI boot. Apex Linux will automatically log into the live terminal with an ANSI welcome banner.

3️⃣

Run Installer

Launch the guided installer with a single command:

apex-guided-installer
